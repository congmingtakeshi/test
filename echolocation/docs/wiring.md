# 配線（ステージ0〜2）

図: `docs/wiring.svg`

注意: ピン割り当ては私の設計案です。まだ実機で確認していません。ESP32-S3-DevKitC-1 と各モジュールのデータシートで確認してから配線してください。

## ステージ0だけならここまで
「マイク2個」と「送信器」だけを配線します。DAC・ボタンは Task 5〜6 まで不要です。

## ピン割り当て

| 機能 | ESP32-S3 | 接続先 | 備考 |
|---|---|---|---|
| 電源 | 3V3 | マイクのVDD、PCM5102AのVIN（モジュールが3.3V入力の場合） | 各マイクのVDDとGNDの間に0.1µFを置く |
| PDM クロック | GPIO4 | マイク2個のCLOCK（並列） | PDM受信は I2S0 を使う想定（要確認） |
| PDM データ | GPIO5 | マイク2個のDATA（並列） | 左右は1本のDATAに時分割で乗る |
| 左右の選択 | - | 左マイクのSELECT=GND、右マイクのSELECT=3V3 | 逆だと左右が入れ替わる。Task 5の左右テストで確認 |
| 送信 A | GPIO6 | MA40S4S 端子1 | 逆相で駆動 |
| 送信 B | GPIO7 | MA40S4S 端子2 | 3.3Vの逆相で約6.6Vppになる |
| I2S BCK | GPIO15 | PCM5102A BCK | DACは I2S1 を使う想定 |
| I2S LRCK | GPIO16 | PCM5102A LRCK | |
| I2S DIN | GPIO17 | PCM5102A DIN | |
| ボタン＋ | GPIO9 | スイッチ→GND | 内部プルアップ |
| ボタン− | GPIO10 | スイッチ→GND | 内部プルアップ |

## PCM5102Aモジュールの設定
- SCK、FLT、DEMP、FMT は GND に接続（モジュールによってははんだブリッジで設定）。
- XSMT は 3V3 に接続（ミュート解除）。
- モジュールの入力電圧（3.3V / 5V）は基板の表示で確認する。

## 安全メモ
- マイクは3.3V専用。5Vを加えると壊れる。
- 送信器は3.3VのGPIO直結で足りる（MA40S4Sの容量は約2000pFで、電流は2mA程度の見積もり。実測で確認）。心配なら各線に100Ωを直列に入れる。
- 使っていないピン: GPIO0/3/45/46（起動設定）、19/20（USB）、26〜37（フラッシュ/PSRAM）。

## 分からないこと
- SPH0641LU4H-1を超音波帯域で動かすために必要なクロック周波数（データシートで確認が必要）
- ESP32-S3 の PDM 受信で、必要なサンプルレートが出るか（ステージ0で確認）
- 手に入るマイクのブレークアウト基板のピン配置

## 保険経路（PCM1808 + MA40S4R）に切り替える場合
マイク2個を外し、PCM1808（I2S ADC）を I2S0 の入力に接続します。MCLK、BCK、WS、DIN に GPIO11〜14 を使う想定です。受信器の増幅回路は別途設計します（必要になった時点で作ります）。
